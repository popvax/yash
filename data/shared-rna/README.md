# Shared RNA evidence

Recorded measurements reused by both vaccine designs:

| Directory | Contents |
|---|---|
| [splicing/](splicing/README.md) | Patient-RNA sequence reconstruction, coding-frame evidence, normal-junction screening and HLA-I predictions. |
| [fusions/](fusions/README.md) | In-frame CDH1::NRG1 sequence, predictions and recorded admission policy. |
| [checkpoints/](checkpoints/) | Original CTA/fusion scored windows, peptide occurrences and RNA-source reference identities. |

These are analysis outputs, with the original source-specific policies and
limitations retained. Each design records how it uses the measurements.
Start with [the data guide](../README.md) for reads, expression, typing and reports.
