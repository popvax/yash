# Historical normal-only checkpoint

These files describe an early nominated normal-DNA audit **before paired discovery
finished**. “Paired result pending” refers to that historical checkpoint.

The [completed reassessment](../final/report.md) supersedes it. Current somatic
assignments and antigen inclusion are in the [selected-antigen review](../antigen-review.md).
Original measurements, allele identities and native receipts remain available here.

`paired-DNA-checkpoint.json/tsv` is the later DNA-only checkpoint before RNA/HLA
review. Its pending flags also refer to that historical stage. The completed
final report supersedes both intermediate checkpoints.
