# Design #1 inputs

These inputs belong to the earlier design generated without matched-normal DNA.

- [Mutations](mutations/README.md): tumour-only DNA assessment, RNA reconstruction,
  peptide predictions and ranking.
- [Checkpoints](checkpoints/): its mutation-region table, internal-junction
  predictions, original verification manifest and prediction-environment records.
- [Shared RNA evidence](../../../data/shared-rna/README.md): splice, fusion and
  CTA/self measurements also reused by the lead design.

The original checkpoint manifest keeps its recorded relative input names.
[The path map](../../../provenance/path-map.json) resolves those identities to
their current locations; measurement bytes and checksums are unchanged.
