# Terminal-junction inference

The request covers all 30 selected antigen regions, 11 linker choices and both
fixed routing elements: 660 terminal options, 14,492 unique peptides and 86,952
peptide–HLA-I pairs. Every query was freshly predicted on Modal with verified
model files and runtime versions. Native Vaxrank enumeration and the mhctools
MHCflurry_Affinity adapter were checked across the complete request.
